# Fantasy Football 2026

Clean rebuild baseline.

- `PLAYERS` is sourced from the exact Yahoo 2026 Player List sync.
- Stars create/remove `TARGETS`.
- `DRAFT` contains targets only, always Yahoo-ranked, grouped into exactly 12 tier slots.
- Desktop Draft is wide; mobile collapses to one tier column.
- No legacy Fantasy Intel HTML or React app is part of this branch.

Yahoo Player List source:
`https://football.fantasysports.yahoo.com/f1/497223/players?status=ALL&pos=O&stat1=S_S_2026`
